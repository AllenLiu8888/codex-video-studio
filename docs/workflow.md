# 从 idea 到可交接的视频

本流程有两条入口。新系列先建立定位与品牌；已有品牌的日常制作从运营文稿开始。用户只委托某个阶段时，交付该阶段即可。长期默认放在 `brand/`，单期选择放在本期配置，已冻结历史保留原样。

## 1. 新系列：定位与品牌

先明确“给谁看、看完得到什么、为什么由这个系列来讲”。把题材范围、事实风险、发布渠道和制作能力写入 [品牌 brief](../templates/brand-brief.md)。设计可替换的视觉语言和可选 IP，按 [品牌系统](brand-system.md) 建立引用索引与验收状态。

完成条件：新会话能定位当前品牌版本、主参考与允许变化；预设中声音/音乐等未知项清楚标记，未经试听不写已接受。

## 2. 选题或接稿

**只有选题时：** 先确定一个观众问题、一个可兑现的结论、足够的可信来源，再写口播。按内容采用问题—解释—例子—回扣，或事件—冲突—转折—启示；结构服务内容，不固定制造“反转”。保存研究证据与口播草稿，避免把研究注释混入朗读稿。

**已有文稿时：** 保存原件与干净逐字稿。默认保留措辞和顺序。事实问题写“原句 → 建议 → 原因/来源”；只有已获改稿授权时才替换。授权可以在系列预设中约定，不需要每次重复询问。标题、来源备注、镜号不进入旁白。

用 `studio.py init --slug <topic> --title <title> --narration-file <file>` 创建独立一期。补齐 BRIEF 的交付范围、声音、画幅、配乐和预算。冻结本期所用品牌、默认设置、文稿及引用文件哈希。

完成条件：原文与制作稿可区分，素材权限和事实风险有处理结论，本期目录唯一，缺失值有明确下一步。

## 3. 正式内容分镜

按语义拆段，每段先写观众所得，再写镜头。依 [方法路由](method-routing.md) 选择静态插画、真实资料、图解、对照或必要片段。每镜保存明确任务书、来源路径、参考职责、构图留白、输出规格及失败退路。

`visual-plan.json` 是镜头清单权威，`storyboard.md` 解释选择理由。字幕位置先计划，再根据实际图片检查。交给独立只读 Agent 反审原文覆盖、事实暗示、方法必要性、重复、IP漂移、制作可行性。保留真实返回，修正阻断问题后绑定最终输入指纹。环境没有子 Agent 时，记录单独检查轮及局限。

完成条件：全文按序覆盖，每镜可执行，方法有信息价值，审查对应最终计划。计划不等于图片已生成或观看已完成。

## 4. 语音导演与校时

按 [语音导演](providers.md#voice-direction) 形成实际请求稿和审核记录。纯旁白、字幕、带服务标记的请求稿分开保存。采用已确认的声音与语速；停顿按语义组织，不对每个标点机械插停。

合成或接入音频后，以实际时间戳/逐句音频长度校时。估算时长只用于初期计划，不能凭字数均分最终时间线。先做低成本预演，检查知识段是否有阅读空间、长句是否憋气、图像是否久停。图片检索和普通静态图可并行；成本高的连续动作在实际时长明确后制作。

完成条件：请求与干净原稿一致，声音参数和审核一致，实际时间可追溯；没有试听条件时标记听感待检。

## 5. 按镜头生产素材

生成图调用当前可用图像工具；真实资料从对象与许可明确的来源取得；图解按核实的知识关系设计。使用当前品牌参考的最小组合。精确文字、公式、品牌字标在后期排版。

每个入片素材保存来源/生成记录、实际输入输出与 SHA-256。实际查看后审核身份、形体、内容关系和裁切；一张修好不代表其他结构保持不变。未验证的动效先做短样，效果差或信息增益不足就改静态图，不为了方法丰富硬塞片段。

完成条件：每镜有有效资产，授权与对象匹配，已知可见错误已处理。使用实际素材重做预演；占位图通过不能替代正式预演。

## 6. 构图字幕、剪辑与混音

字幕放在实际画面的留白区域；同一句展示期间位置稳定。检查相邻镜头叠化时两张图的遮挡，不用一套底部坐标覆盖所有构图。保持可读行数、字号与平台安全边距。基础镜头推拉和淡化也应克制，避免每个元素同时运动。

按素材和实测声音统一剪辑，明确短片段是否保留原声。音乐采用已许可配置，先保证人声可辨，再校准响度、峰值、让位和首尾。默认无音乐也可完成视频；不要悄悄下载来源不明曲目或循环补足长度。

完成条件：最终 MP4 含正确画面、旁白、字幕和需要的音乐；技术设置与本期配置一致。渲染成功仍需检查。

## 7. 验证、交付与迭代

技术检查绑定最终文件哈希：完整解码、画幅/fps、时长、音轨、字幕顺序和输出。视觉检查实际字幕帧、转场、首尾裁切及内容；听感检查专名、漏读、节奏与配乐。技术、助手视觉、实际播放、听感和用户接受分开记录。

交付成片、干净稿、音频/字幕、来源署名、简洁交付报告及可复现配置。用户要求不播放时只做允许的离线检查，明确剩余听审/验收，不自动打开媒体。发布另按已有授权执行。

返修从最早受影响阶段开始：换音乐复用有效视觉与旁白；换图重做相关预演和布局审查；改稿或声音重建配音及校时；品牌升级创建新版本。旧结果、输入快照与原审核保留。每期 BRIEF 记录最终 run 和下一步，系列共性优化在维护任务中更新，避免生产任务争改全局规则。
