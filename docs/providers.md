# 图片、语音与成本

运行时负责剪辑；生成服务由当前 Codex 环境和本期配置决定。先运行 `studio.py doctor`，再检查实际可用工具与账户。已安装技能、已配置密钥、服务可调用和已成功生成是不同状态。

## 图片

Codex 能使用内置图像生成工具时，按镜头任务直接生成/编辑并保存返回文件。仓库本身不提供一个冒充该工具的 HTTP API。没有这个能力时，可接入用户已有图片或明确配置其他生成服务；依然保存输入输出与来源。

使用当前环境可见的正式工具参数。不要把某个网上技能的名字当作获得指定后台模型的证据，也不要宣称能无限使用订阅额度。工具不公开模型版本、随机种子或逐图用量时，记录为未知。

图片预算先按实际镜头需求估计，保留少量修图余量。相邻句子可以共享同一个语义镜头；无意重复同一图片、仅换裁切覆盖大量不同内容，会降低辨识度。先用关键身份镜、知识图和互动图做小样，通过后再批量生成。

## 语音

可用两类输入：配置的语音 API，或用户有权使用的本地音频。当前适配器能力和 JSON 字段见 [运行手册](runtime.md) 与模板；新增服务先做短样、确认时间戳/对齐方案，再写成支持能力。

供应商、模型、voice ID、语速、音高/音量、停顿策略集中保存。`01`、`02` 等可作为项目自己的声音别名，但它们不是跨账户通用标准。初次选声用同一段文字比较；确认后日常制作继承预设。每次模型或声音改变，重新检查对应的官方操作要求和中文表现。

密钥只留本机受忽略的环境文件或环境变量。默认不打印请求中的鉴权字段，不把真实密钥写入品牌快照、日志或 Git。成功生成保留请求指纹和缓存；提交结果不明时先查现有状态，避免盲目重复付费。

## Voice direction

配音前单独完成语音导演节点：

1. 读取锁定纯稿、本期声音/语速、模型支持语法和目标语气。
2. 按语义分呼吸组：解释后的停顿、转折前后、列举层次、情绪回落。紧密短语保持连读，不对每个逗号加标签。
3. 检查数字、英文缩写、专名、品牌名及多音字。只使用实际适配器支持的标记或参数；导演备注放在说明里，不能被朗读。
4. 保留纯稿。当前节奏检查契约只允许插入支持的停顿标记和调整空白；它不支持把改字、音译或发音字典假装成已验证能力。若确需扩展，先记录原词对应、取得必要改稿授权并实现短样验证，不让字幕悄悄变稿。
5. 优先由独立只读 Agent 返回节奏稿与原因，主制作 Agent 保存原始返回并检查正文一致性。无子 Agent 时记录独立检查轮的真实身份。
6. 合成前绑定请求稿、参数和审核哈希；合成后按实际音频检查停顿、总时长、读音与情绪。文本审核不等于听审。

停顿参数是请求意图，不保证最终静音长度完全一致；标点和模型本身也会产生停顿。以实测音频为准。字幕拆行服务阅读，不应机械决定语音停顿。

## 配乐

音乐默认可关闭。项目可选一个默认曲和最多两个备选，记录实际文件、来源、作者、许可、署名文本和哈希。授权要覆盖计划的发布用途；只在本机试听不等于已获得传播许可。

混音从人声可辨开始，实测响度和真峰值；背景音乐在讲话时平滑让位。推荐值可以作为项目起点，不能代替最终测量或听感。换音乐时复用有效视觉轨与旁白。没有合适授权音乐时，交付无配乐版本比随意抓取歌曲更可靠。

## 成本与授权

制作前记录可接受的预算和重试范围。费用按实际供应商、地区、模型、计价单位与查询日期核对；仓库不保存会快速过期的“统一最低价格”。本地演示不调用付费服务。

如需要比较订阅额度，记录同一账户在测试前后的可见额度窗口、时间和并行活动。账户共享窗口的变化不能精确归因到单张图；仅报告观察差值和限制，不换算成虚构的逐图成本。
