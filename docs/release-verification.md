## 首次使用测试反馈与修正

1. 长片方法说明曾与引擎最多两个复杂运动段冲突；保留引擎上限，说明默认 0、最多 2，长内容先拆片或显式扩展并验证引擎。三段反例实际被 design 拒绝。
2. 补齐 MIT 许可证、第三方说明与密钥/生产目录忽略规则。真实项目资料默认留在本地。
3. 增加本地音频方向模板；不要求每个使用者开通 MiniMax。
4. 修复本地音频同名替换的缓存和审核绑定，导入前后均校验源文件。
5. 对齐字体许可清单与实际文件名。

最终版本以 GitHub Release 对应提交为准。环境缺失时运行 doctor；内容审核缺失时回到对应制作节点，不能自动填写通过状态。
