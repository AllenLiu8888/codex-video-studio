# 首尾画面与完整交付

本页约定 Agent 的制作与交付工作。音频路由、开头亮度由渲染器执行；素材打包和文稿对比 PDF 由 Agent 使用可用工具完成，目前没有自动打包或 PDF 导出命令。

## 首镜与主题

首镜先让观众认出本期主题，并与开场原句共同成立。有主持角色的品牌，可以表现角色与主题对象的具体关系：观察、托扶、放置、对照或使用。让动作体现内容，避免所有期数只换道具而保持同一个姿势。优先一张关系完整的静态画面配安全缓动，必要时才制作连续动作。

无角色品牌可用主题对象、真实资料或图解开场。品牌一致性不要求每期增加人物。为首句字幕留出空间，检查主体、手部/物体接触、裁切与下一镜叠化。保持已批准的开场文稿，额外口号或标题朗读须有改稿授权。

`opening.style=visible_smooth_lift` 从同一首镜的可见亮度柔和提亮，默认参数见初始化配置。检查第0帧及提亮过程，避免插一帧封面后回黑。省略 `opening` 保留旧黑淡入。首帧可见不保证每个平台采用它作预览封面；平台效果需要真实发送验证。

## 可替换的品牌尾卡

品牌可选一个清晰的尾卡母版，在 `brand/active-ip.json.references` 中以 `role: "brand_endcard"` 保存项目相对路径和真实 SHA-256；没有角色时该索引仍可保存品牌图形。初始化会校验并冻结引用。母版可以是图形、字标、产品或场景，具体选择由品牌约定决定。

Agent 把选定母版作为 `prepared_image` 明确列入末镜，保留制作来源记录、准确 Logo/字标和字幕安全区。渲染器不会自动识别或插入尾卡；实际末镜必须出现在本期资产、分镜和时间线中。末句按本期批准稿显示，不从另一片借口号。尾卡改变时建立明确修订，历史文件与快照保留。

## 完整素材包

每次交付成片，同时提供可直接下载的素材 ZIP，在交付报告和验收页列出链接。修订包绑定本次最终 run；保留之前的交付包。只补交素材时注明对应成片版本。

- 按期和实际镜头顺序收齐全部入片图片，包含首尾图，保留原尺寸、原字节。附实际使用的原始照片、未排字图解底板、视频片段、品牌图层等可用源件，标清与成图的对应关系。
- 附干净旁白、SRT、收到的原稿、最终口播稿、分镜/时间线、本期配置、实际提示词、生成/来源记录，以及使用过的品牌参考和声音设置快照。有可编辑图层或排版脚本时一并提供；没有制作的工程文件如实注明。
- 保留出处、署名与核实过的许可。仅包含本期实际使用素材及必要依赖；密钥、`.env`、缓存、废弃候选、无关历史与临时审核文件留在工作区。参考素材有交付限制时先列明限制并提供允许的替代记录，不把本地读取权限当成再分发授权。

完成条件：逐镜对照最终 `timeline.json`、`sources.json` 和本期资产，核对没有漏图/漏片；清单记录期数、镜号、用途、尺寸、来源、包内相对路径和 SHA-256。检查 ZIP 完整性，并逐文件比对源件与归档字节哈希。缺失源件列明具体项目，不能仅凭 MP4 宣称完整素材已交付。本地交付不等于对外发布。

## 已授权改稿的全文对照

文稿有修改时，随成片交付对比 PDF 和可编辑源稿。每期先简列改动，再左右并排完整原文与完整最终稿，对齐对应段落；未改文字完整保留。修改句以醒目颜色和①②编号标注，标题改动也编号；下方按相同编号解释原因，事实理由附可追溯来源，编号每期重置。

优先每期一页，内容过长时优先保留可读字号。逐项核对最终文稿、实际语音请求和字幕，区分事实纠错、避免绝对化、表达简化与比喻调整；合法停顿标签与排字标点可单独说明。导出后查看全部页面的文字、换行和分页。无修改时注明“原稿未改”。这份附件记录已授权变更，不扩大改稿权限。

完成条件：全部实际措辞变化都能对应原句、最终句和原因；PDF 与本次最终成片一致；下载链接可用。技术检查、Agent 看图、听感和人类接受分别记录。
