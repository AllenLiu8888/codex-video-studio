# 领域规则：替换内容约束，保留制作机制

选本期需要的段落阅读。新的领域可以增加一份短规则：可信来源、更新时效、事实与观点边界、版权/隐私约束、合适的呈现方法。无需复制整套工作流。

## AI 科普

把一个问题缩小到观众能带走的一个机制或判断。技术结论优先对照原始论文、官方文档、模型报告或可重复实验。区分模型版本、实验条件与产品功能；用玩具例子解释机制时标明简化，类比不证明真实内部过程。

适合：静态结构图、输入/输出对照、少量可读的实例、来源明确的产品界面。图中节点、箭头与关系应先由内容计划确定，不能让图像模型自行发明科学结构。示例输出注明实际测试与构造示意的区别。

## AI 新闻 / 产品更新

在研究记录中写清“截至日期、发布日、事件发生日、版本、地区/账户适用范围”。先找第一方公告，再核对是否已经实际可用。预告、测试、全面上线不是同一状态。若争议影响结论，呈现来源冲突而非拼成确定事实。

适合：日期卡、官方资料引用卡、经过许可的截图、前后功能对照。生成画面作为解释插图，不伪装新闻现场或官方界面。价格、能力和榜单在发布前重新核查；本地制作通过不代表新闻仍然最新。

## 讲书 / 观点解释

优先明确书名、作者、版本、章节与可定位的观点出处。分开“作者原意”“创作者的概括”“延伸例子”。引用只取解释所需的短片段，保留出处；不要把整章内容改写成可替代原作的完整朗读。歌词、诗句及强表达性的短文本要额外谨慎，无法确认权限时用概述或自写例子。

适合：观点关系图、生活场景、短引文排版、公开许可的作者/书籍资料。书封、影视片段、插图不是因为出现在网上就可以复用；按本期授权记录处理。

## 名言 / 历史人物 / 小故事

核对名言原文与出处；无法找到可靠原始来源时标为“常被归于”并说明不确定，或改成不署名的创作表达。区分史实、传说、文学改编与虚构故事。具体年份、地点、人物关系需要证据，不用意象图片替代事实核查。

适合：经核实的档案照片、地图/时间线、年代明确的器物图；缺资料时用清楚标注的情景插画。历史照片必须对应真实对象，不能把“看起来像那个时代”当作证据。

## 情绪 / 生活方式 / 品牌故事

主观感受和意象可以创作，功效、科学与历史陈述要有来源。把“这个物品让我想到……”与“它能治疗/改善……”区分。心理安慰或生活建议不能被图文包装成未经证明的医疗作用。

适合：静态情境插画、真实物品、品牌角色与克制留白。让具体情境推动内容，减少每期都出现同一窗边、同一道光、同一托物姿势的惯性。

## 证据记录

使用 [文稿与事实记录](../templates/claims-and-script.md)。记录主张、对应原句、来源页、可定位段落、访问日期、适用范围、结论和实际采用的措辞。截图/下载文件也登记来源与许可。创作稿保持干净，研究备注留在记录中。
