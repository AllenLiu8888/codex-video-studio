# 根据内容选择画面方法

选法顺序是“观众要理解什么 → 画面需要表现什么关系 → 采用哪种方法”。不要先决定本片必须含照片、动效、拼贴，再把文稿塞进去。

| 内容任务 | 默认方法 | 适合升级的情况 | 检查点 |
| --- | --- | --- | --- |
| 情绪、类比、角色陪伴 | 品牌静态插画 | 局部运动确实强化表达 | 类比不冒充事实；具体场景与本期有关 |
| 人物、器物、事件、真实产品 | 可核实照片或授权截图 | 连续观察对理解必要时用真实视频 | 对象/时期/出处准确；许可允许用途 |
| 定义、组成、结构、流程关系 | 标注图、剖面、静态信息图 | 连续变化本身就是知识点，且短样验证有效 | 科学结构先审；精确标签后排 |
| 两类差异、误区、前后状态 | 对照图、并列卡、少量关键状态 | 状态之间的变化不能用静图讲明白 | 比较尺度、条件和单位一致 |
| 动作、步骤、操作 | 关键帧序列、少量定格或短视频 | 需要看见操作路径或时间过程 | 时间足够、动作正确、字幕不抢焦点 |
| 抽象观点、书中启示 | 具体生活情境、关系图、意象 | 原授权资料更有解释力 | 作者观点与创作者解释分开 |
| 品牌收束、行动提示 | 品牌落版或安静主图 | 明确的情绪/传播目的 | 字标准确、内容不过度重复 |

“真实资料纸本拼贴”是一种可选的品牌处理方式：用边框、纸张、标签或留白把照片接进整体设计。现代科技品牌也可用清晰的编辑卡片。处理不应改变证据本身的关键颜色、比例、人物或结构。

## 四个维度分开记录

- **来源**：生成、自拍、客户提供、公共授权、授权片段。
- **方法**：插画、照片卡、标注图、对照、关键状态、短视频。
- **外观**：配色、纸纹或其他材质、线条、明暗。
- **剪辑**：静止、轻推拉、叠化、字幕淡化。

同一种方法可以有丰富的构图和明暗；换来源不自动等于换风格。先保证片段与内容对应，再评估整体变化。

## 克制运动

默认主力是静态图。解释动效不作为开箱即用的必选方法；只有当前工具能准确表现、短样审查通过且比静图多传递信息时才启用。没有必要可完全不用。当前稳定引擎默认 0 个复杂运动段，每片最多 2 个；次数是上限，不是任务指标。长内容优先拆片；确需超过 2 个时，先显式扩展并验证引擎，分镜计划不能自行绕过限制。

同一时刻让一个主体承担主要运动。真实视频、镜头推拉、粒子、字幕和背景都消耗注意力，不能只统计“动画段数”。片段不足时应补素材或改计划，显式记录末帧停留；不用无意义的循环掩盖时长不足。

## 避免系列趋同

每期在分镜中写一个“独有观察”：一个具体对象、关系、场景或证据。对照最近作品的关键帧，检查是否只是把同一人物姿势与同一背景换了名词。

允许品牌色按段落改变比例；景别、视角、空间、对象和证据类型也可变化。IP可以只出现在开场、转折或结尾，不必覆盖知识本体。无需平均分配方法，连续几镜同一方法只要内容和构图有推进，也比无目的切换更自然。

## 字幕是构图的一部分

生图前计划留白，取得图片后检查最终裁切。框坐标按成片画幅填写；保护人物脸部、手部、关键道具、科学标注和证据对象。字幕在同一句内不移动；相邻镜头能共用位置就保持。检查叠化时两图同时可见的遮挡与文字可读时长，不靠不断缩小字号解决。
