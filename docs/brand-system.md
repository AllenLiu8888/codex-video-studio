# 品牌与角色参考包

“Seed”在这里指可复用的品牌/IP参考包。数值随机种子只是部分生成服务的参数；同一个数值不能保证跨模型、跨版本或跨构图的人物一致。

## 先定义品牌，再决定是否需要人物

用 [品牌 brief](../templates/brand-brief.md) 固定受众、内容承诺、语气与差异点。设计一套小而明确的视觉语法：主/辅/强调色的职责、材质、线条、光影、图形母题、排版和留白。配色比例可以按语义变化；真实对象的识别特征和科学关系应保留。

有主持角色的系列适合用 IP 建立连续性。严肃新闻、历史档案、产品演示也可能更适合字标、排版和图形系统。把“每期有统一身份”与“每镜都有人物”分开。

## 参考包的最小闭环

| 文件/内容 | 用途 | 何时需要 |
| --- | --- | --- |
| 品牌 brief 与视觉规则 | 说明定位、语气、固定项、可变项 | 所有系列 |
| 调色板与字形/字体来源 | 控制可替换配置和授权 | 所有系列 |
| 清晰独立的身份母版 | 锁定角色外观 | 有角色 |
| 必要视角、局部或互动参考 | 处理预计会出现的结构风险 | 按镜头需要 |
| 实际场景验证样本与观察 | 证明哪些条件下可用 | 生图系列 |
| 当前参考索引与 SHA-256 | 新会话定位当前版本，追溯旧片 | 所有系列 |
| 接受/待检记录 | 区分候选、助手初检与人类接受 | 所有系列 |

不用为了“完整”堆满几十张图。一个清楚的身份母版加少量职责明确的辅助图，通常比包含矛盾版本的大拼版更好用。总览卡用于介绍；生成时优先引用无排版、单主体的母版。

## 固定项与可变项

固定项要可观察，例如“一个圆形观察窗位于上半部中央”“侧标总为短珊瑚色矩形”。可变项包括动作、视角、表情、环境、景别与品牌色占比。避免把“高级、好看、温柔”当作唯一身份规则；它们无法判断某个细节是否漂移。

为角色写一小段身份说明，不锁死某个姿势。不同参考分别负责身份、局部结构、动作或构图。场景任务明确本镜可见部位；近景不需要把画外全身结构硬塞进画面。

## 验证与版本

先验证预计会用到的明显不同场景：例如正面中景、三分之四侧面与一次物体互动。若无角色，则验证近景对象、解释图和大留白构图。记录实际看到的优点和错误；未测试角度保持未测试，不宣称所有未来输出都稳定。

采用 [验收模板](../templates/seed-acceptance.md)。当前索引指向已选版本；候选保留在候选目录。后续更换母版或关键规则时升级品牌版本，新期冻结新引用，旧期不重写来源。每镜仍需实际查看，参考包完整只代表能够开工。

系列首镜和统一尾卡按[首尾画面](finishing-and-delivery.md)规划。尾卡母版可用 `brand_endcard` 参考职责加入当前索引，实际入片仍需明确配置末镜；角色不是必填项。

## 给生成工具的镜头任务

```text
镜号与用途：
画幅、输出规格：
本镜观众应看到的关系：
主体、动作/状态、视角、景别：
环境、光影、材质：
品牌固定项：
本镜允许变化：
参考文件和各自职责：
字幕留白、主体保护区域、裁切余量：
需要后期排版的文字/标记：
不适用或不可见的部位：
```

保存实际展开后的提示词；“按品牌风格”本身不是可复现任务。工具没有公开后台型号、精确随机种子或单次额度时，在记录中保留 `null`/unknown。
