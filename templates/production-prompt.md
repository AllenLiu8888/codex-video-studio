# 新制作会话 Prompt

使用本项目的 `$video-studio`，先读仓库 AGENTS、当前项目状态与相关技能。我的目标是用下方文稿完成一版本地成片，沿用已确认的品牌/IP参考、声音、语速、节奏、字幕与配乐预设。

请创建唯一的新一期目录，保存原稿和本期设置快照；不要覆盖其他任务或修改历史验收。文稿默认保留原词和顺序，标题与备注不进旁白；遇到实质事实问题，按项目已约定的改稿权限处理，并保留原句、修改与原因。

先完成正式分镜：逐段说明观众所得、镜头内容、采用的方法、具体提示词/素材任务与失败退路。以适合品牌的静态图片为主，真实资料、静态知识图、对照或小片段仅在内容需要时采用，不硬凑方法数量。品牌角色可出现，也可以让知识对象独立承担镜头。

完成独立分镜反审和语音导演检查后再批量制作。正文、字幕和语音请求稿分开；按实际语音模型支持的方式安排语义停顿，沿用已选声音/语速，用真实音频时间戳校时。

调用当前可用工具生成/检索素材，保留实际提示词、参考职责、输出和来源/许可记录。实际查看图片后决定字幕位置，保护主体、标注和关键动作；同一句位置稳定。剪辑与音乐先保证内容和人声清楚，保留旧结果以便返修。

完成后对最终成片进行实际可执行的技术、视觉和听感检查，准确说明哪些未检查。交付视频、文稿、字幕、声音、来源署名与简洁报告，更新本期 BRIEF 让新会话可直接接手。已有制作授权内持续做到交付；涉及实质冲突、未授权的新增费用或对外发布再提出具体问题。
