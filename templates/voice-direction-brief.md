# 语音导演交接

- 纯稿文件 / SHA-256：
- 实际声音配置：provider、model、voice、speed
- 本期目标语气：
- 当前模型操作要求来源 / 查询日期：
- 实际适配器支持的节奏与发音能力：
- 已授权改词范围：

## 给节奏审核 Agent

请作为只读口播节奏导演，按原词和原顺序组织语义呼吸组。返回：

1. 实际请求稿，只使用该适配器支持的语法；标题和导演备注放在稿外。
2. 哪些解释、转折、列举、回落处需要停顿，哪些短语应该连读。
3. 数字、缩写、品牌/人物名和多音字的风险；超出适配器能力的处理建议单独列出。
4. 原文一致性、参数一致性、模型要求与未解决问题。

此时尚未生成音频，请只报告文本检查，不声明听感。运行环境无子 Agent 时，由主 Agent另做检查轮并准确记录身份。

## 主制作 Agent 保存

- `audio/request-text.txt`：实际请求正文。
- `audio/agent-response.md`：原始审核返回。
- `audio/direction.json`：按运行时模板填写真实 reviewer、response_sha256、原稿/请求稿 SHA、实际声音与模型要求。
- `episode.json`：绑定请求稿与审核文件 SHA，参数与实际调用一致。
