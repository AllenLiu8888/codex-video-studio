# Brand Seed

Use from this repository; read [brand system](../../../docs/brand-system.md) and the user's existing brand files. Here “seed” means a reference package, not a numeric random seed.

1. Fill [brand brief](../../../templates/brand-brief.md) from the user's idea, intended audience, channel and differentiator. Record unknowns; choose reversible draft defaults where appropriate. Preserve an existing brand unless redesign was requested.
2. Define a small visual grammar: palette roles, image treatment, composition, typography, evidence-media treatment and permitted variation. Explain how the grammar serves the audience. Character-free documentary or product brands are valid outcomes.
3. If a character is needed, define a compact set of visible identity anchors and flexible attributes. Generate a clean identity master before expression/pose sheets. View the actual image and reject contradictions or unstable details; a mood board does not establish identity.
4. Create only the supporting views/details required by expected shots, plus a few meaningfully different validation scenes. Assign each reference a role. Use current image tools and record the actual prompt, settings and output; unknown backend model or numeric seed stays unknown.
5. Assemble the reference index and [seed acceptance record](../../../templates/seed-acceptance.md). Freeze the accepted version; keep candidates separate. User acceptance, assistant visual checks and file-integrity checks are different states.

Reuse the approved master and the minimum relevant auxiliary references per shot. Stable output comes from references, explicit invariants, shot-specific prompts and review together; a fixed random number cannot guarantee identity.

Complete when another session can locate the master, distinguish fixed and variable attributes, select the right references, see what was tested, and know what remains untested. Brand initialization does not require a production video or every imaginable pose.
